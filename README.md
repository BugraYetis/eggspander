# 💪 EGGSpander — Fitness Ürün Tanıtım Sitesi

> GSAP ScrollTrigger ile scroll-driven animasyonlu ürün tanıtım deneyimi

## 🌐 Demo
**[Canlı Demo](https://www.eggspander.com/index_en.html)**

## ✨ Özellikler
- GSAP ScrollTrigger ile scroll-driven animasyonlar
- SVG path stroke animasyonları
- Before/After interaktif slider
- Full-viewport (100vh) immersive bölümler
- Paralaks efektler ve görsel geçişler
- Responsive mobil uyumlu tasarım

## 🛠️ Teknolojiler
`GSAP` `ScrollTrigger` `SVG Animations` `Vanilla JavaScript` `CSS3` `Responsive`
