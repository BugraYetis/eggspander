## 📌 Proje Hakkında

Taşınabilir fitness cihazı EGGSpander için geliştirdiğim tanıtım sitesi. GSAP ScrollTrigger ile scroll-driven animasyonlar, SVG path çizimleri, before/after slider ve immersive full-viewport deneyim sunuyor.
